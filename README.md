# Adsorption_Energy_Distribution
This Jupyter Notebook models the Adsorption Energy Distribution (AED) of As(III) on MnFe2O4 nanoparticles via NNLS optimization. It implements Langmuir and Fowler-Guggenheim kernels, calculates capacity (17.98 mg/g) using Simpson's rule, partitions mechanisms at 8.0 kJ/mol, validates fits, and exports 300 DPI dual diagnostic plots.
